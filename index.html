📱 Instalacja na Androidzie i GitHub Pages

1. Jak zainstalować aplikację na telefonie z Androidem?

  1. Otwórz adres swojej aplikacji w przeglądarce Google Chrome na telefonie z Androidem.
  2. Kliknij przycisk „📲 Zainstaluj (Android)” w prawym górnym rogu aplikacji (lub otwórz menu Chrome ⋮ i wybierz „Dodaj do ekranu głównego” / „Zainstaluj aplikację”).
  3. Aplikacja pojawi się jako pełnoprawna ikona Redukcja Pro na pulpicie telefonu i działa również offline!

2. Jak umieścić aplikację za darmo na GitHub Pages?

  1. Utwórz nowe repozytorium na GitHubie (np. redukcja-pro) i prześlij wszystkie pliki z tego folderu (index.html, styles.css, app.js, manifest.json, sw.js, ikony).
  2. Wejdź w zakładkę Settings → Pages w swoim repozytorium.
  3. W sekcji Build and deployment (Source) wybierz Deploy from a branch, wskaż gałąź main (folder /root) i kliknij Save.
  4. Po ok. 60 sekundach Twoja aplikacja będzie dostępna pod adresem https://twoj-login.github.io/redukcja-pro/ z obsługą HTTPS i PWA!

📲 Instalacja na telefonie Android

Aby zainstalować Redukcja Pro jako aplikację na telefonie z systemem Android:

  1. Upewnij się, że strona jest otwarta w przeglądarce Chrome (przez HTTPS, np. na GitHub Pages).
  2. Dotknij ikony menu ⋮ (trzy kropki w prawym górnym rogu przeglądarki).
  3. Wybierz opcję „Zainstaluj aplikację” lub „Dodaj do ekranu głównego”.
  4. Potwierdź klikając Zainstaluj. Ikona pojawi się wśród Twoich aplikacji!
